# Перечисления и Типы

## EPipelineStatus
Определяет статус пайплайна в текущем режиме.

```cpp
enum class EPipelineStatus {
    NONE = 0,        // Статус отсутствует
    READY = 1,       // Пайплайн готов к работе
    STOPPED = 2,     // Пайплайн остановлен
    PLAYING = 3,     // Пайплайн активен и работает
    RESTARTING = 4,  // Пайплайн перезапускается
    INITIALIZED = 5, // Пайплайн инициализирован
    COUNT = 6        // Количество состояний
};
```
Поле json в запросах для взаимодействия с камерами: `status`

## EPilelineType
Вид дополнительного потока внутри камеры. Определяет, какой из аппаратных потоков камеры будет обрабатываться. `SUB` поток нужен только для отображения.

```cpp
enum class EPilelineType {
    NONE = 0,  // Поток отсутствует
    MAIN = 1,  // Основной поток
    SUB = 2,   // Дополнительный поток
    COUNT = 3  // Количество типов потоков
};
```
Поле json в запросах для взаимодействия с камерами: `type`. Поле должно находиться в потоках

## ECameraType
Вид камеры. Определяет, к какой системе относится камера и какой из модулей системы может ее использовать.

```cpp
enum class ECameraType {
    NONE = 0,     // Камера не определена
    GENERAL = 1,  // Общего назначения
    NEURAL = 2,   // Камера для нейронных алгоритмов
    BIRDVIEW = 3, // Камера для вида сверху
    COUNT = 4     // Количество типов камер
};
```
Поле json в запросах для взаимодействия с камерами: `type`. Поле должно находиться в камерах

## ERtspType
Производитель камеры. Влияет на формирование ссылки для получения видеопотока.

```cpp
enum class ERtspType {
    NO_PRODUCER = 0, // Производитель не определен
    DAHUA = 1,       // Dahua
    HIKVISION = 2,   // Hikvision
    ACE = 3,         // ACE
    COUNT = 4        // Количество производителей
};
```
Поле json в запросах для взаимодействия с камерами: `production`
