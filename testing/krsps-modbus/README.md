# krsps-modbus — стенд Modbus АС КРСПС

Программный стенд модуля `modbus` шлюза (конфигурация «Искра»): ведущий АС КРСПС
по протоколу v2.3 на `os.openpty()` вместо USB–RS485, заглушка
`/api/neural/status` бэкенда и одноразовый шлюз. Железа не нужно: на .102 нет
ни адаптера RS-485, ни socat, ни pyserial — хватает python3 из системы.

## Запуск

На машине мастера, из корня репозитория:

```
python3 testing/krsps-modbus/stand.py --image varan/message-gateway:<тег>
python3 testing/krsps-modbus/stand.py --image … --keep     # оставить рабочий каталог, при ошибках — лог шлюза
python3 testing/krsps-modbus/stand.py --serve http://127.0.0.1:9090
```

Сценарии поднимают шлюз `mbstand-gw` в сети хоста на портах 19090 (REST) и
15051 (gRPC) с файлом настроек в `/tmp/mbstand-*`, бэкендом
`http://127.0.0.1:18000` (заглушка стенда) и выключенным CAN. Живой шлюз
(9090/50051) не трогается. Записи шлёт `sender.py` в образе
`varan/detection-service:latest`: там есть grpc, заглушки proto собираются из
`message-gateway/proto` при старте. Шлюз видит pty через `-v /dev/pts:/dev/pts`.

`--serve` — ведущий для живого шлюза с активной «Искрой»: ставит модулю порт pty
и раз в 5 с пишет время и GPS, читает состояние и записи, отмечает прочитанные.

## Что проверяет

| Раздел | Проверки |
|--------|----------|
| блок состояния | 0x1000–0x1005 = 20, 1, 32, 0x1000, 3, 1; 0x1002 — длина единственного пакета 28163; ведущий на связи |
| регистр 0x1007 | 1 при всех слотах и плитках в работе; 0 и причина: плата не в сети, нет техзрения, слот остановлен, плитка без камеры, нет плат, бэкенд 503; причина текстом в `state.registers` |
| скрытые записи | до времени ведущего 0x1006 = 0 и окно пустое; после — время сдвинуто на разницу ведущего и часов платы, раскладка 28163, GPS из записи и нули без GPS |
| время и GPS | `/time` с источником `modbus`, буквы полушарий в любом порядке, знак южной широты и западной долготы, координаты без букв отвергнуты |
| отметка | неверные номера не снимают ничего, 1..2 снимает с головы, отметка тремя записями 0x06 |
| исключения | 0x03, 0 и 126 регистров, адреса вне 0x1000–0x2FFF, запись в 0x8000, неизвестная команда, байт счёта |
| мусор и CRC | мусор и неверный CRC без ответа, мусор вплотную перед запросом, счётчики |
| чужой адрес | запросы ведомому 21 без ответа, его ответы не считаются ошибками |
| широковещательная | запись времени адресом 0 исполняется без ответа |
| перезапуск | видимые записи и время поднимаются из файла, новая запись скрыта до времени ведущего и переживает второй перезапуск |
| 65535 -> 0 | номера 65534, 65535, 0 и отметка через переход |
| окно из целых записей | 130 записей по 40 регистров: в окне 102, хвост нулями, отметка 103 отвергнута, 102 — снимает окно; 0x1002 = 0, пока в очереди записи по 40, и 32 после них |
| переполнение | при 65 535 записях выбрасывается старейшая, новая получает №1 |
