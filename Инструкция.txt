Для установки необходимо сначала закачать образ orangepi5pro_rsm.img на диск ssd, так же нужна SD карта любого размера, чтобы записать загрузчик для SSD rkspi_loader.img

После того, как все закачка прошла, нужно расширить файловую систему на самом SSD до максимума. Для этого нужно зайти по ssh на устройство. IP адпес выдается по DHCP, необходимо смотреть в роутере, логин и пароль: orangepi orangepi
Далее выполняем последовательно эти команды:
sudo parted /dev/nvme0n1

В строке пишем:
resizepart 2 100% # увеличение раздела до максимума, соглашаемся на все, если будет писать
quit

sudo partrobe /dev/nvme0n1 # Если команда не найдена - пропустить
sudo resize2fs /dev/nvme0n1p2

Готово, фаайловая система расширена.

Шаг 5. Разворачивание контейнеров приложения
Основные docker-compose лежат в папке с репозиторием (/home/orangepi/varan/RJD либо /opt/RJD)
Делятся на 2 вида:
docker-compose.master.yml - мастер-докер, отвечающий за фронт, передачу по can и websocket, а также за маршрутизацию устройств в приложении.
docker-compose.miniom.yml - докер, который отвечает за связь c развернутым media-center, для каждого устройства должен быть свой миньон.

Если на одном устройстве крутится и media-center, и фронт необходимо разворачиваить сразу 2 вида. Если только media-center - нужен только миньон. Мастер в целой сети должен быть только один.
Для этого варианта сборки необходим доступ в сеть:

Каманда для разворачивания мастера (необходимо находиться в пути репозитория):
(sudo) docker compose -f docker-compose.master.yml up --build -d

Для разворачивания миньона:
(sudo) docker compose -f docker-compose.minion.yml up --build -d

Шаг 7. установка media-center.service

вызвать команду sudo nano /etc/systemd/system/media-center.service, в нее вставить содержимое файла "media-center.service"

Описание части файла сервиса:
StateDirectory=varan
WorkingDirectory=/opt/media-center/0.0.1
ExecStart=/bin/bash -lc 'source /opt/gstreamer-1.28/env.sh && exec /opt/media-center/0.0.1/media-center \
    --rest-port=7777 --signaling-ip=127.0.0.1 --signaling-port=8765 \
    --modules=birdview,neural \
    --varan-root=/var/lib/varan \
    --gateway-ip=127.0.0.1 --gateway-port=50051'


Что здесь важно: 
--modules отвечает за то, какие модули будут доступны на этом устройстве. На 192.168.1.2 - neural, на 192.168.1.4 - birdview, в случае если необходимо запускать все на одной машине, пишется сразу оба модуля
--gateway-ip - ip адрес устрйоства, на котором запущен мастер docker, именно там находится шлюх для отправки сообщений
--varan-root - основная папка, где хранятся конфигурации настроек, калибровки, нейронные модели. На всех новых машинах путь уже стоит в /var/lib/varan, на старых пусть по /home/orangepi/varan (при этом там же и RJD и media-center)
Порты необходимо оставлять как есть, дополнительной настройки не требуется. Чтобы сигналинг работал необходимо запускать docker-compose.minion везде, где запущен media-center

Шаг 8. Перенос необходимых настроек на устройства. Все необходимые файлы находятся в папке доп пакеты.

- Перенос тайлов карты на устройство по пути /storage/journal - взять из journal. Перенести папки, как есть 
- Перенос настроек калибровки: по пути варана (/var/lib/varan либо /home/orangepi/varan) перенести surround_view, здесь можно выбрать, что необходимо - пресеты калиборовки (calibration/calibration_settings.json вместе c папкой calibration/maps/), модели (presets/models/), neural - с конфигурацией модели и самой моделью.
- Все, что лежит в varan - зеркало файлов, сохраняет используемые пути

Так же можно сохраняить отдельные параметры со старого устройства, чтобы использовать их в новой версии.
