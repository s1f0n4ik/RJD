## Шаг 1: Запуск
cd <directory>
docker compose up --build

Подожди 30-40 секунд, пока контейнеры инициализируются.

Шаг 2: Проверка
Откройте в браузере:
Swagger UI: http://localhost:8000/docs
WebSocket тест: открыть файл python-varan/client/test_websocket.html
Health check: http://localhost:8000/health

Шаг 3: Добавление камеры через Swagger
Открыть http://localhost:8000/docs
Найти POST /api/camera
Нажать "Try it out"
Вставить JSON:
{
     "camera_name": "TestCamera",
     "rtsp_url": "rtsp://admin:password@192.168.1.100:554/stream",
     "width": 1920,
     "height": 1080,
     "reconnect_interval": 5
   }

Нажать "Execute"
Шаг 4: Просмотр MJPEG стрима
После добавления камеры открой:
http://localhost:5000/neural_1

Остановка
docker compose down

- Docker >= 20.10

🔧 Примеры использования API
Добавить камеру
curl -X POST http://localhost:8000/api/camera \
  -H "Content-Type: application/json" \
  -d '{
    "camera_name": "Camera_1",
    "rtsp_url": "rtsp://admin:password@192.168.1.100:554/stream",
    "width": 1920,
    "height": 1080,
    "reconnect_interval": 5
  }'

Получить список камер
curl http://localhost:8000/api/cameras

Создать загрузчик
curl -X POST http://localhost:8000/api/loader \
  -H "Content-Type: application/json" \
  -d '{
    "loader_name": "Loader_1",
    "weights_path": "/models/yolov5s.rknn",
    "img_size": 1024,
    "server_endpoint": "/neural_1",
    "loader_matrix": [["Camera_1"], ["Camera_2"]]
  }'

Запустить загрузчик
curl -X POST http://localhost:8000/api/loader/Loader_1/start

Получить общий статус системы
curl http://localhost:8000/api/status

🐛 Troubleshooting
Проблема: Flask недоступен из FastAPI
Симптом:
Flask server unavailable: Connection refused

Решение:
Убедитесь, что в .env указано:
FLASK_BASE_URL=http://flask-server:5000

Проблема: Контейнер падает сразу после старта
Проверка логов:
docker-compose logs flask-server
docker-compose logs fastapi-server

Возможные причины:
Неверный синтаксис в Python коде
Отсутствующие зависимости в requirements.txt
Порт уже занят на хосте
Проблема: MJPEG стрим не работает
Проверка:
Камеры запущены?
curl http://localhost:8000/api/cameras

Загрузчик работает?
curl http://localhost:8000/api/loaders

Проверь endpoint:
curl -I http://localhost:5000/neural_1
